Working Together

Live co-editing, directly between computers.

DraftCraft lets you edit the same script at the same time as other writers. The computers talk to each other directly (peer to peer), so there is no company server in the middle and no account to create.

Starting and joining a session

Both options are in the Tools menu:

  • Start a Live Session starts a session that other writers can join.
  • Join a Live Session connects you to a session someone else started.

If two computers cannot find each other

Sometimes two computers cannot reach each other directly. In that case, a relay code gets them connected. The relay only passes along traffic that is end-to-end encrypted.

This page will grow as the feature does. If something is unclear, open an issue from the Help and Feedback page.
