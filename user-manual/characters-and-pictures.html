Characters and Pictures

Character sheets, photos, and the Asset Manager.

Character sheets

Each character can have a profile with photos, backstory, and other details. Anything that Final Draft has no place for is kept in the .dcraft file beside your .fdx. See Saving and File Formats.

Removing a photo

Hover a character photo and click the trash can. DraftCraft asks you to confirm and shows a preview of the picture, so you can be sure it is the one you meant.

  • If the picture was added just for that character, it is removed for good.
  • If the picture is also used elsewhere in the script, it is only taken off this character, and the picture stays.

After you confirm, an Undo button appears for about ten seconds. The script is also marked as having unsaved changes, so closing it asks whether to save.

The Asset Manager

The Asset Manager lists every picture in your script. You can remove a picture from there too, and it offers an Undo in the same way.
