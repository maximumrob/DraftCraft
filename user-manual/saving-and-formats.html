Saving and File Formats

Why .fdx is the default, and when a .dcraft file appears.

Final Draft (.fdx) is the default

DraftCraft saves your script as a Final Draft file by default. Anyone with Final Draft can open it, and you can open theirs.

When you get a .dcraft file

Final Draft has no place for a few things DraftCraft can keep. When your script uses any of these, DraftCraft saves a .dcraft file beside your .fdx, so nothing is lost:

  • pictures and assets
  • character relationships
  • version history
  • location details

The .fdx keeps the screenplay itself, so it still opens everywhere. The .dcraft keeps the extras too.

Going back to .fdx

If a script no longer needs any of those extras (you removed its last picture, say), pressing Save asks Save as Final Draft? You can choose Save as FDX or Keep .dcraft. DraftCraft asks once per file each time you open it, and only when you press Save yourself, never during an automatic save.

Unused pictures

If the only thing keeping a script as a .dcraft is pictures that nothing in the script uses, Save shows an Unused pictures box with a small preview of each one. Choose Remove them to delete them for good (this cannot be undone), or Keep them to leave everything as it is. After you remove them, the Save as Final Draft question follows.

Other formats

DraftCraft can open and export Final Draft, Fountain, Fade In, Open Screenplay Format, Word, and PDF files.
